查看计算依据与边界约定

压力指数

0–100 分
P=30D+30B +20(1−C)+20A
D考试密集度
D=min(1,E74)

E7：未来 7 天的考试场次
达到 4 场时，密集度取 1

B任务积压率
B=ToT

To：逾期未完成任务数
T：总任务数，本页固定为 20

C任务完成率
C=TcT

Tc：已完成任务数
完成率越高，未完成项的压力贡献越低

A考试临近度
A=min(1,21d)

d：最近考试剩余天数
此式适用于 d > 0，当天规则见下方

边界与联动规则

  • 示例范围本页总任务数固定为 20，并始终保留一场最近考试。
  • 任务计数逾期未完成任务数不超过剩余未完成任务数，已完成项不重复计入积压。
  • 考试当天剩余天数为 0 时，临近度直接取 1，避免除以 0。
  • 日期联动未来 7 天考试为 0 场时，最近考试至少在 8 天后；剩余天数设为 7 天内时，考试场次至少为 1。

分值对应的状态

  • 0 ≤ P < 40轻松
  • 40 ≤ P < 60适中
  • 60 ≤ P < 80偏压
  • 80 ≤ P ≤ 100高压

示例分值用于呈现计算规则，不是心理诊断。
