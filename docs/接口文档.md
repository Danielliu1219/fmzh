# 《期末周别慌！》API 接口文档

- 统一前缀：`/api`（开发时前端通过 Vite 代理 `http://127.0.0.1:8000`）
- 认证方式：除注册/登录外，请求头需带 `Authorization: Bearer <access_token>`
- 交互式文档：后端启动后访问 http://127.0.0.1:8000/docs
- 错误格式：`{"detail": "错误描述"}`，常见状态码 400（参数/业务错误）、401（未登录）、404（不存在）、409（账号已存在）、502（AI 调用失败）

---

## 一、认证 `/api/auth`

### 注册（成功即自动登录）
`POST /api/auth/register`
```json
{"username": "testuser", "password": "test123456", "nickname": "小明", "student_no": "", "major": "", "grade": ""}
```
响应 `200`：
```json
{"access_token": "eyJ...", "token_type": "bearer", "user": {"id": 1, "username": "testuser", "nickname": "小明", "student_no": "", "major": "", "grade": "", "created_at": "..."}}
```
约束：username 3-20 位字母数字下划线（唯一，重复返回 409）；password 6-32 位。

### 登录
`POST /api/auth/login`，body `{"username": "...", "password": "..."}`，响应同上；账号或密码错误返回 401。

### 获取当前用户 / 修改资料
```
GET  /api/auth/me
PUT  /api/auth/me    body: {"nickname": "新昵称", "major": "..."}（字段均可选）
```

## 二、考试 `/api/exams`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/exams` | 我的考试列表（按考试日期升序） |
| POST | `/api/exams` | 录入考试 |
| PUT | `/api/exams/{id}` | 修改（字段均可选） |
| DELETE | `/api/exams/{id}` | 删除 |

创建 body：
```json
{"subject": "高等数学", "exam_date": "2026-09-12", "location": "教三101", "duration_minutes": 120, "note": "闭卷"}
```

## 三、复习资料 `/api/materials`

### 上传（multipart/form-data）
`POST /api/materials`
| 字段 | 说明 |
|---|---|
| file | 文件（.txt / .pdf / .docx，≤20MB） |
| title | 标题（必填） |
| exam_id | 所属科目（可选） |
| source_type | 历年题 / 老师重点 / 课堂笔记 / 作业 / 练习题 / 其他（默认"其他"） |
| description | 说明（可选） |
| tags | 标签（可选） |

上传后自动解析正文存入数据库；解析失败资料仍保存，`parse_status` 为 `failed`。

### 列表（筛选）
`GET /api/materials?exam_id=1&keyword=极限&source_type=历年题`（参数均可选）

### 详情 / 删除
```
GET    /api/materials/{id}    响应含 text_preview（解析文本前 1000 字）
DELETE /api/materials/{id}    同时删除磁盘文件
```

## 四、AI 分析 `/api/ai`（核心）

### 第一次调用：生成用户画像
`POST /api/ai/profile`
```json
{"exam_id": 1, "raw_text": "我这门课基本没学，只想及格，还有五天考试"}
```
响应 `200`：
```json
{
  "exam_id": 1,
  "raw_text": "我这门课基本没学，只想及格，还有五天考试",
  "target": "pass",
  "learning_status": "weak",
  "available_days": 5,
  "daily_hours": null,
  "weak_chapters": [],
  "output_need": ["知识点权重", "复习计划", "自测题"],
  "is_complete": false,
  "missing_fields": ["daily_hours"]
}
```

### 补全画像
`POST /api/ai/profile`（同一接口，supplement 会追加到已保存的描述后重新提取）
```json
{"exam_id": 1, "supplement": "每天能学3小时"}
```

### 第二次调用：生成复习分析
`POST /api/ai/analyze`
```json
{"exam_id": 1}
```
前置条件：画像已完整（否则 400）；该科目至少有一份解析成功的资料（否则 400）。
响应 `200` 的 `result` 字段为固定 JSON（详见 docs/系统设计.md §4.2）：`course`、`summary`、`knowledge_points`、`exam_focus`、`review_plan`、`quiz`。
**副作用**：`review_plan` 自动生成该科目的每日任务（替换旧的 AI 任务）。

### 查询最新分析
`GET /api/ai/analyses/{exam_id}` — 无历史分析时返回 404。

## 七、特色功能 `/api/features`

压力指数与情绪评分公式见 README 第 3.3、3.4 节，实现照抄不改。

### 期末压力指数（7.1）
`GET /api/features/pressure`
```json
{
  "score": 52.0, "level": "适中",
  "suggestion": "压力适中，保持当前节奏",
  "breakdown": {"exam_density": 0.25, "task_backlog": 0.4, "task_done_rate": 0.375, "exam_proximity": 1},
  "need_emergency": false
}
```

### 情绪自评与查询（7.6）
- `POST /api/features/mood`，body `{"mood_score": 3, "note": ""}`，mood_score 取 1~5；重复提交覆盖当天记录
- `GET /api/features/mood/today` — 今天没有记录返回 `null`

```json
{
  "record_date": "2026-09-07", "mood_score": 3,
  "emotion_item": 2.5, "completion_item": 1.67, "pressure_item": 3, "streak_item": 0,
  "composite_score": 2.1,
  "suggestion": "状态偏低，建议减轻今日任务或暂停半天",
  "need_relief": true
}
```

### 临时救急模式（7.2）
`GET /api/features/emergency?exam_id=1`（exam_id 可选，默认取最近一场考试）
从该科目最新 AI 分析里抽「必考/常考考点 + 高权重知识点」成冲刺清单；无分析时 `note` 给出提示，无待考考试返回 `null`。

### 考前重点回顾列表（7.3）
`GET /api/features/review?exam_id=1`（exam_id 可选）
按权重从高到低列该科目必看知识点，每条含 `suggest_hours`（建议复习时长）；无分析时 `note` 提示。

### 今日最重要的三件事（7.4）
`GET /api/features/top3`
在今日（含逾期）未完成任务中按 `40×优先级权重 + 35×截止紧迫度 + 25×(压力/100)` 打分取前三，`reason` 说明置顶原因；无待办时 `note` 提示。

### 学习时段推荐（7.5）
`GET /api/features/timeslots`
按画像 `daily_hours` 把复习时间分配到早/上午/下午/晚上四个时段；无画像时按默认每日 3 小时并给 `note`。

```json
{
  "daily_hours": 4, "learning_status": "medium",
  "slots": [
    {"name": "早晨", "start": "07:30", "end": "09:00", "minutes": 70, "focus": "攻坚薄弱环节：极限与连续"}
  ],
  "note": ""
}
```

### 低情绪减负与计划重排（7.7）
- `GET /api/features/relief?option=lighten|halfday` — 预览重排方案，**不落库**
- `POST /api/features/relief/apply`，body `{"option": "lighten"}` — 确认后重排并写入

约束：不晚于该科考试日、每天不超画像可用时长（halfday 今日容量取 0，lighten 取一半）、按优先级高→低安排；排不下的任务进 `conflicts` 提示取舍。

```json
{
  "option": "lighten", "daily_hours": 4, "today_capacity": 120,
  "moves": [{"task_id": 5, "title": "第5天：综合题与易错点", "from_date": "2026-09-10", "to_date": "2026-09-11", "minutes": 150}],
  "conflicts": [],
  "summary": "将后移 1 个任务，今日负担相应减轻"
}
```

## 八、管理端 `/api/admin`（仅管理员）

所有接口要求当前用户 `is_admin=true`，普通账号访问返回 403。管理员身份由 `User.is_admin` 标记（`seed_demo.py` 已将 demo 设为管理员）。

### 课程 / 科目维护（8.1）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/courses` | 课程/科目列表 |
| POST | `/api/admin/courses` | 新增，`{"name":"高等数学","code":"MATH101","teacher":"张老师","credit":5,"term":"2024秋","note":"闭卷"}` |
| PUT | `/api/admin/courses/{id}` | 修改（字段可选） |
| DELETE | `/api/admin/courses/{id}` | 删除 |

### 异常账号与内容治理（8.2）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/users` | 账号列表（含考试数/资料数、`is_admin`、`is_banned`） |
| POST | `/api/admin/users/{id}/ban` | 封禁（封禁后无法登录，且所有接口 403；不能封自己） |
| POST | `/api/admin/users/{id}/unban` | 解除封禁 |
| GET | `/api/admin/materials?keyword=` | 全站资料列表（内容治理，可按标题搜索） |
| DELETE | `/api/admin/materials/{id}` | 删除违规资料 |
