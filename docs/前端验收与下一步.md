## 本轮前端交付

- 首页按“今日优先 → 任务执行 → 总进度与专注 → 压力与情绪 → 考试与考点回顾”组织。新增考试票据、数字层级、细线分隔与紧凑的辅助信息，减少所有内容堆成相同卡片的情况。
- 今日任务、接下来、已完成、全部四种筛选；置顶任务可直接打卡，并注明未来任务可以提前复习。
- 总进度、各科完成数、考试时间线进度统一从任务列表计算；0%、部分完成、100% 均使用同一响应式组件。
- 每周打卡点按 `done_at` 的实际日期生成；提前完成未来任务会记在完成当天，撤销会移除该条证据。今天尚未打卡时保留截至昨天的连续记录。
- 考试倒计时按日历日期计算；已结束考试不再被后端的“负数截为零”误认为今天开考；首页采用用户自选科目颜色。
- 专注计时按真实截止时间校正，避免后台标签页定时器节流累积误差；暂停、重置及离开页面时保存整分钟，保存失败保留重试机会。已开始的一轮锁定科目与时长。
- 特色建议请求失败不挡住核心任务；失败提示可重试。手机导航可以横向滚动，不再把文字挤成竖排；补键盘焦点、跳转正文、减少动态效果支持与小屏弹窗限制。
- AI 分析补结构化目标表单、知识点重点视图、结果概览与参考提示；首页按科目的分析链接会带入所选科目。首次没有历史分析属于正常空状态，不再弹错误通知。
- `VITE_USE_MOCK=false` 可选择真实接口；默认仍为演示，服务器数据不会因预览操作被修改。切换无需改源代码。

## 下一步按这个顺序做

1. **先补自测的学习闭环（张诗琪 + 胡歆桐）**：4.6 作答、判分、答案解析、3.5 错题自动入本，再把结果接入 4.9 掌握状态与 4.12 计划调整。完成标准：提交一套答卷 → 有得分与逐题反馈 → 错题入本且去重 → 再次登录可查看。不要把“显示答案”算成已判分。
2. **补站内提醒（张诗琪）**：6.1 / 6.2，先有提醒时间字段、到期检查接口与已读状态，再做通知入口。只在打开 / 刷新时检查；不要用没有真实通知的红点装饰首页。
3. **收齐日程需求（许丽媛）**：2.5 起止时间与重复规则 → 2.8 真实时段冲突 → 2.9 日 / 周 / 月视图。三项共用同一时段模型，避免只升级日历外观。
4. **完善 AI 内容与依据（胡歆桐）**：资料权重手动调整、来源建议、思维导图 / 记忆卡片、资料问答、真实题型频次。先补可追溯数据，再扩充图表；不要把模型一句“高频”画成不存在的统计次数。
5. **收尾共用能力与交付（宋跃月 + 全组）**：9.3 全部重要操作确认、9.4 操作日志、7.1 每日计算、5.3 周报、既有审查修单；最后进行真实数据全流程验收与部署。静态 Pages 预览与完整前后端部署分别验收。

建议下一轮继续沿用现有配色，重点打磨“自测作答 → 错题复习 → 统计反馈”的三个页面；它比增加装饰性首页组件更能体现系统特色。
