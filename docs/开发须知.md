## 一、先把项目跑起来（十分钟）

前置：Node.js ≥ 18、Python 3.10+。两条路，建议都跑一遍。

### 1. 只看界面（不需要后端，最快）

```bash
git clone <仓库地址>
cd <仓库目录>/frontend
npm install          # 首次需要，比较慢，npm 慢就换镜像：npm config set registry https://registry.npmmirror.com
npm run dev
```

浏览器打开 http://localhost:5173 ，登录页底部有「**免登录预览（无后端）**」按钮，点进去就是完整首页，数据是本地假数据。

> 原理：`frontend/src/mock/dashboard.js` 里 `USE_MOCK = true`。**你平时开发前端就保持 true**，改界面不用等后端。

### 2. 完整联调（前端 + 后端）

终端 1，起后端：

```bash
cd <仓库目录>/backend
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Windows
copy .env.example .env                            # Windows；`.env` 没进仓库，必须自己复制一份
.venv/Scripts/python run.py                       # http://127.0.0.1:8000，接口文档 /docs
.venv/Scripts/python seed_demo.py                 # 灌演示数据（账号 demo / demo123456）
```

终端 2，起前端：把 `frontend/src/mock/dashboard.js` 的 `USE_MOCK` 改成 `false`，再 `npm run dev`，用 demo / demo123456 登录。

后端默认 `LLM_MOCK=true`，**不需要申请 DeepSeek Key**，AI 分析会返回内置示例数据，全流程能走通。

### 3. 改完代码自己验一遍

```bash
cd backend && .venv/Scripts/python smoke_test.py    # 后端改了就跑，自动走注册→录考试→传资料→AI 分析→打卡
cd frontend && npm run build                        # 前端改了就跑，确认能构建
```

## 二、日常开发流程

1. **每人一个分支**，不要直接往 main 上提交。分支名 `dev-姓名拼音`，比如 `dev-xuliyuan`。
   ```bash
   git checkout main
   git pull                       # 每次开新活之前先拉最新的 main
   git checkout -b dev-xuliyuan
   ```
2. **做完一个用例就提一次 PR**（Pull Request），别攒一大堆。PR 写清楚：做了哪个用例、改了哪些文件、怎么验的。
3. **组长审查后合并**。合并进 main 之前 main 必须能跑起来。
4. 提交信息用中文说清做了什么，例如 `完成个人资料编辑页面（用例 1.4）`。
5. **接口有任何改动，立刻同步改 `docs/接口文档.md`** —— 你改了不改，别人就按老接口写，联调必炸。
6. 做完一个用例，顺手去 `README.md` 第 2 节的状态表里把这一行的 ⬜ 改成 ✅（🔧 表示只做了一部分）。

## 五、会遇到的坑

1. **加字段/加表**：项目用 `Base.metadata.create_all()` 自动建表，只认新表，**不改已存在的表结构**。所以你给现有表加字段后，要删掉 `backend/fmzh.db` 重启后端重新建表，再跑一遍 `seed_demo.py`（本地测试数据会没，是正常的）。
2. **中文路径**：项目路径别带中文和空格，有人 clone 到 `E:\问题求解实战` 能跑，但保险起见放英文目录（如 `D:\code\fmzh`）。
3. **Windows 控制台中文乱码**：跑 Python 脚本统一加前缀 `python -X utf8 脚本名.py`。
4. **前端调不通接口**：先看是不是没起后端（8000 端口），再确认 `USE_MOCK` 是 false，再看 `frontend/vite.config.js` 的代理（`/api` → `http://127.0.0.1:8000`）。
5. **AI 分析报错**：确认 `backend/.env` 里 `LLM_MOCK=true`，这样不花钱也能演示。
6. **npm 装依赖很慢**：`npm config set registry https://registry.npmmirror.com`。
7. **加了后端依赖**：写进 `backend/requirements.txt`，让别人 `pip install -r` 能装上；前端同理写进 `package.json`。
