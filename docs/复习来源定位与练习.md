# 复习来源定位与练习（2026-11-03）

任务需要给出可以直接学习的资料位置。新版在原有两次核心模型调用中增加来源编号选择：第一次仍然提取画像；第二次分析时同时读取本机建立的题目/课件索引，给知识点及任务返回 `source_ids`。建立索引、查看原页、收藏不会的题均不调用模型。

## 使用方式

- AI 分析的知识点、复习计划，以及首页当前任务、课程任务列表、日历任务详情中，会显示“练习：资料名 · 第几题 · 第几页”或“阅读：课件名 · 第几张幻灯片”。
- 打开来源后，PDF 自动显示原页图片，可切换跨页题目的页码、放大或下载原文件。图片资料显示原图；PPTX 保留真实幻灯片号，DOCX 保留段落/表格行，旧 PPT 保留实际文本段号，可下载原文件核对排版与公式。
- 综合题保留共同题干和 `(1)/(2)` 小问；同一题可以关联多个知识点。本地题号规则可能误分题，界面明确提示核对原页，无法识别时保留原页/段落，不编造题号。
- “分步复习”是阅读、独立作答/复述、核对、回顾的通用步骤，不冒充具体题目的解题解析。“对照原文答案”只展示同一片段中明确标出的答案；其他页答案需查看原文件。
- “标记不会”保存识别题干、原文答案（若有）、知识点及带版本的来源定位到错题本。相同来源版本重复标记去重；资料内容更换后保留旧记录，不覆盖旧题。
- “请 AI 给解题提示 / 参考解答”仅在用户点击时额外调用模型，按钮旁说明消耗 Token。请求在服务端校验账号、科目及来源版本，并优先放入指定题目/课件原文；回答在资料问答历史中保存，模型生成解答不标成原卷标准答案。

## 旧计划与手动修正

旧分析没有模型选择的来源编号，系统用已有真实引文或保守关键词匹配定位，并明确标注匹配方式；这不代表已确认题目适合训练该知识点。找不到时显示“暂无匹配来源”，可以浏览本科全部题目/课件，并在具体任务中点击“将此来源加入本任务”。每项最多关联8个来源，支持取消。

任务的来源编号独立保存到 `tasks.source_ids_json`，编辑、容量拆分、全科重排、反馈重排均保留。手动换科目会清除旧科目的来源。来源列表按账号和科目隔离，原文件及原页需登录鉴权，浏览器使用授权请求获取 Blob，不把 Key 或登录令牌放进 URL；文件响应禁止公共缓存。

## 当前边界

- 本地索引依据现有解析文字和真实位置，不是对每道题额外做一次模型分析。公式、扫描、分栏、题号格式特殊时仍可能识别不足，应以原页为准。只清理显示控制字符，不猜测修复数学符号。
- PDF 提供整页原图，可能包含相邻题目；没有裁剪出题目边界。PPT/Word 暂不提供逐页图片渲染，使用幻灯片/段落定位及原文件下载。
- 没有可靠页码的旧资料明确显示文本位置。解析失败或纯扫描 PDF 尚未提取到文字时，不能自动建立准确题目与知识点关联。
- 模型上下文仍按每份约6000字、合计30000字截取，包括来源编号和位置，以控制输入费用；未送入模型的来源不会被接受为该次模型选择。全部本地索引仍可浏览、手动关联，不能将模型局部输入当作完整试卷统计。
- 项目不再发送输出 Token 上限，思考模式保留；模型平台自身的输出与上下文限制仍然有效。每日调用次数配额与 Token 上限是不同设置，现有调用配额保持不变。

## 验证入口

后端运行 `backend/.venv/Scripts/python.exe backend/run_tests.py`，该入口在导入应用前使用假 Key、Mock 默认配置，并禁止测试进程连接外部地址；真实 HTTP 协议回归只访问本地假上游。请勿在个人付费 `.env` 环境中直接运行未隔离的历史测试命令。

本机数据库升级前创建加密备份，隔离副本验证两次升级后逐表原字段记录不变，再对本机执行同样升级。原有资料文件和分析结果不重写；旧计划无须重新付费生成即可浏览来源。
